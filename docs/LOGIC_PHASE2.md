# 第二阶段扩展逻辑与一致性

本文仅描述新增题库、版本、复用、共享、跨问卷统计及认证和提示变更。基础问卷生命周期、四题型校验、跳转执行和提交保存见未经修改的[第一阶段逻辑说明](LOGIC.md)。

## 来源题编辑入口与并发约束

原无source题目继续使用普通编辑接口；有source的题库快照必须创建新版本后在草稿中显式换版，避免来源和内容不一致。更新仍沿用_id、草稿状态与revision条件的单文档原子更新。发布和关闭问卷不支持换版。

## 题目族、版本与快照

题目族ID连接版本、分享与使用查询；版本ID对应不可变内容及摘要；问卷实例ID负责答案与跳转。题库内容不含依赖具体问卷的规则。指定版本导入时复制完整内容，生成新实例并记录source={question_id,version_id,content_hash}。

草稿换版保留实例ID和规则，验证整卷后再按revision写入。题型或选项变化导致条件失效时拒绝，原快照和修订号保持不变。发布和关闭状态不接受换版。

版本只插入。唯一的(question_id,request_key)用于同请求重试，(question_id,version_no)仲裁并发编号；同键异内容拒绝。恢复旧版本生成新记录并标注恢复来源，父版本可显式指定形成分支。最新版本按序号读取，无跨集合可变指针。


## 分享、使用查询与统计

分享只授予查看和复用题目的权限，不授予原问卷或答卷权限。撤销阻止后续查看与导入，不改变已复制快照。使用查询只返回当前用户自己的问卷；合法持有快照时，即使分享撤销，仍能查看自己的使用情况和统计。

整卷与单题统计即时读取指定问卷的答卷；允许重复提交时按有效答卷计数，不按独立用户去重。跨问卷查询先过滤所有者，再用source定位题目族，并按version_id分别汇总。相同答卷含多个实例时计多次回答，但总答卷数去重；即使恢复内容摘要相同，不同版本也不合并。摘要不一致时停止统计。数字频数分布为精确答案值计数，不是区间直方图。


## 认证页面与密码兼容

static/auth.js只负责登录与注册视图，app.js负责认证后导航；后端继续使用原auth接口，未另建账号系统。注册不发会话令牌，成功回登录；确认密码仅在前端检查。分享路径在视图切换后保留，已有会话直接进入业务页。

RegistrationCredentials限制新密码8～16字符，Credentials允许登录8～128字符。Python与前端按Unicode码点计数，不按UTF-16单元截断；PBKDF2哈希、盐和会话格式不因密码上限变化而迁移。


## 从问卷复制与重复请求

复制接口同时检查源问卷和目标题库所有权，从服务端快照提取QuestionInput内容，不信任客户端传来的完整题目。实例编号、source和跳转规则不进入通用题库版本；规则目标依赖具体问卷。复制不写回surveys或responses，不影响发布、关闭问卷及已有答卷。

同一复制者、同一问卷实例和内容摘要生成确定性题目族标识，同内容并发或重试只保留一族一初版，跨题库只追加归属；草稿内容改变后再次复制形成独立题目。若来源题目确属本人且旧版本内容相符，复用原题目族及完整历史，不用旧内容覆盖新版本。自己的问卷若持有他人合法共享快照，可保存为独立自有题，不获得原作者管理权限。题库归属按集合式追加，重复加入返回added=false及明确提示。


## 中文提示与错误处理

后端将模型、数据库和未预期错误转换为中文JSON响应；技术堆栈仅记录在服务端。前端检查状态、Content-Type和JSON有效性，遇到纯文本、HTML、损坏JSON或网络错误显示中文说明，不暴露原始响应、状态码或英文异常。API字段名及HTTP状态码仍供程序使用。

数字越界提示分别为“输入的数字不能低于最小值。”和“输入的数字不能超过最大值。”。选择数量、规则条件、目标选择、内容变化和版本不匹配提示采用操作说明；问卷状态与运算符映射为中文，版本及答卷以可读字段展示。浏览器原生必填和格式校验也提供中文提示。离线API页面保留协议结构，加载失败仍用中文说明。


## 新增功能的边界

题库版本不可变属于应用接口约束，直接操作数据库仍可能绕过。共享撤销与已授权的在途导入没有跨文档事务，撤销不追溯修改已导入快照。跨问卷统计在内存汇总，精确数字分布不等于区间直方图；无source的旧题目不自动归族，恢复内容相同也不合并版本统计。
