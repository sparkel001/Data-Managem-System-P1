# 关键逻辑与实现边界

## 模块

app/config.py 管理环境配置；auth.py 认证与所有权；surveys.py 生命周期；questions.py 题目定义与答案校验；logic.py 规则检查与路径执行；responses.py 填写保存；statistics.py 统计；static/ 是不依赖 CDN 的 HTML/CSS/JavaScript。

## 生命周期与编辑一致性

草稿可以修改标题、说明、匿名、多次填写、截止时间、题目与规则。至少一道题且截止时间在未来才能发布。状态转移为 draft → published → closed，关闭不可重新开启；到期仍保留 published 状态，但所有填写接口返回 410。发布时间之后不允许编辑结构，避免旧答卷与新题目混淆。

草稿更新条件同时包含 _id、status 和 revision，用 MongoDB 单文档原子更新递增 revision。两个请求并发修改时，旧修订请求返回 409，请刷新后重试。发布也采用同一机制。问卷所有者过滤在每个管理与统计入口执行，不能用 URL 猜测访问他人的管理数据。

## 跳转

题目 ID 到序号建立映射；遍历每条规则检查操作符、条件类型、选项值、目标存在。目标必须位于当前题之后，或 END。这是有向无环图的简单约束：每次跳转使序号递增，因此最多访问题目数量次，能够结束。前向限制刻意不支持回跳。执行器另有已访问集合防护，以避免外部错误数据导致死循环。

每题按顺序匹配规则，命中首条即跳转；无命中顺序进入下一题，最后一题默认 END。多选 any 表示至少一个条件选项被选中；all 表示全部条件选项被选中，允许额外选项。选答空值不触发规则。

服务端根据答案重算路径，只校验经过的题目；被跳过的必答题不要求填写。未知题目、路径外答案会被拒绝。next 接受路径前缀，供网页逐题填写；submit 从第一题完整重走，不相信客户端的跳转结果。

## 校验

选择题至少两项、ID 唯一；多选答案不能重复、不能包含未知项，并检查上下限。文本按 Python 字符数计数（非字节数），拒绝仅空白的非空答案。数字拒绝字符串、布尔值和非有限数，检查范围及整数条件。配置上下限也要校验，避免保存永远无法满足的约束。前端显示提示，后端是最终判定者。

## 保存与并发

每次有效提交写入独立 responses 文档。禁用重复填写时生成 once_key=survey_id:user_id，部分唯一索引在数据库层处理并发；允许多次时省略该字段。一次答卷写入是原子的。失败校验不会写答卷。

MongoDB 单机部署不要求副本集。状态检查与答卷插入跨两个文档，未使用事务：关闭/截止判断以请求校验时为准；已经通过检查且正在执行的提交可能在关闭后极短时间内写入。此语义适合课堂演示，若未来要求严格关闭瞬间截断，应引入副本集事务或提交协调机制。

## 统计与隐私

只查指定问卷的答卷；读取现有答案即时计算，无缓存同步问题。当前实现将答卷载入内存统计，适用于课堂数据规模；大规模应用可改为聚合管道与分页，不改变答案 ID 模型。

匿名是对创建者隐藏身份。responses 详情采用白名单，统计只读取 answers。管理员仍可看到内部用户关联；文本回答可能主动透露身份。实名答卷详情显示用户 ID 和用户名。

## 第一阶段范围

已实现本次九个 BLOCK。没有实现第二阶段未知需求，也没有实现删除问卷、删除/重排题目、导出答卷、服务端草稿答卷自动保存、找回密码或互联网部署。当前“保存”指成功提交后持久化，刷新未提交页面会丢失填写内容。页面返回上一题会清空该题答案，要求重新填写以重新计算分支。运行在本机；浏览器数字使用 JavaScript Number，超大整数不适合精确采集，手机号若要保留前导零宜用文本题。
